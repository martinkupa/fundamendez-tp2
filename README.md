# TP1 Fundamentos de Programacion 
Este es un trabajo practico de C para la materia Fundamentos de Programacion. 
Para compilar y ejecutar la build de debugging hacer

> $ make \

Para compilar con el comando de la consigna
> $ make release

Para ejecutar el juego
> $ ./juego

Para compilar y ejecutar el test suite
> $ make tests \
> \$ ./test_suite

Para compilar de cero
> $ make clean

Para comprimir
> $ make zip

### Notas al corrector
El programa se compone de 6 librerias: _restaurant_, _restaurant_utils_, 
_generador_, _restaurant_io_, _vector_operaciones_ y _vector_pedidos_. El 
formateo puede ser medio inconsistente por que lo hice a mano, no estoy 
familizarizado con ningun formatter de C.
